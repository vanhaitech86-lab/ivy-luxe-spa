2. CÁCH SỬ DỤNG TRÊN MÁY TÍNH CÁ NHÂN:
--------------------------------------------------------------------------------
- Không cần cài đặt phần mềm phức tạp:
  Chỉ cần giải nén file zip, nhấp đúp chuột vào file "index.html" để mở website ngay lập tức trên bất kỳ trình duyệt nào (Chrome, Cốc Cốc, Edge, Safari, Firefox).
- Để mở trang quản trị admin, nhấp đúp chuột vào file "admin.html".
- Để chạy máy chủ cục bộ (Localhost) nếu muốn:
  Mở thư mục trong VS Code và cài tiện ích "Live Server", hoặc mở bằng Node.js / Python:
  + Python: `python -m http.server 8088`
  + Node.js: `npx serve .`
